# CT Checker — サイクルタイム測定アプリ

製造現場の作業時間（サイクルタイム）をその場で計測し、ばらつき・タクトタイムとの関係・
ライン全体のネック工程まですぐに確認できるブラウザアプリです。ライブラリ・サーバ・
インターネット接続は不要で、タブレットやスマートフォンのブラウザでそのまま使えます。

## 2つの測り方

| | 使い方 | 向いている場面 |
| --- | --- | --- |
| **1工程を細かく** | 1サイクルを「要素作業」に分けてラップ計測（最大8個） | 標準作業の時間観測、要素ごとのムダ探し |
| **複数工程を同時に** | 工程を最大6個登録し、1画面で並行してラップ計測 | ラインバランス分析、ネック工程の特定 |

工程を1つだけ登録すれば前者、2つ以上登録すれば後者になります。切り替え操作は不要です。

## 使い方

`index.html` をブラウザで開くだけです。

```bash
# ローカルサーバ経由で開く場合（推奨）
python3 -m http.server 8000
# → http://localhost:8000/
```

ファイルを直接ダブルクリックして開いても動作します（Safari ではデータの自動保存が
無効になることがあるため、上のようにサーバ経由での利用を推奨します）。

現場端末に配布するときは、1ファイルにまとめたビルドが便利です。

```bash
node scripts/build-single.mjs   # → dist/ct-checker.html
```

`dist/ct-checker.html` は CSS・JS を内蔵した単一ファイルなので、USB メモリやメールで
配って、オフライン端末でそのまま開けます。

## 主な機能

**計測**

- 大きなボタンをタップするだけのラップ計測。`Space` キーと数字キーにも対応
- 複数工程を同時計測（工程ごとに独立したサイクル記録・取消・破棄）
- 1サイクルを要素作業に分けた観測（工程ごとに設定できます）
- **取消**（押し間違いを1つ戻す。サイクルをまたいで戻れます）
- **破棄**（イレギュラーが起きた進行中サイクルを捨てて測り直す）
- **一時停止 / 再開**（停止中の時間は計測に含まれません）
- 計測中は画面が消えないようスリープを抑止（対応ブラウザのみ）

**集計** — 「ライン全体」と工程ごとを表示切替で行き来できます

- ライン全体：ネック工程、ラインバランス効率、工程平均の合計、工程間の差、タクト超過工程
- 工程ごと：平均・中央値・最小・最大・レンジ・標準偏差 σ・ばらつき CV、タクト比較
- 要素作業ごとの平均・最小・最大・σ・CV・構成比
- 異常値は明細の「除外」で統計から外せます。±2σ を超えるサイクルの一括除外にも対応

> ラインバランス効率＝各工程の平均の合計 ÷（工程数 × ネック工程の平均）×100。
> 100 % に近いほど工数の偏りが小さいことを示します。

**グラフ**（インライン SVG・ライト／ダーク両対応）

- 工程別の平均サイクルタイム（山積み表。最小〜最大のひげ、タクト線、ネック工程の ▲）
- 工程別サイクルタイムの推移（工程ごとの折れ線）
- サイクルタイムの推移（要素作業ごとの積み上げ、平均線・タクト線、超過サイクルの ▲）
- サイクルタイムの分布（ヒストグラム）
- 要素作業ごとの平均時間（横棒＋最小〜最大のひげ）

**データ**

- 入力内容と計測結果はブラウザに自動保存され、閉じても復元されます
- 名前を付けて複数の測定を保存し、読み込み・比較・削除ができます
- CSV 書き出し（Excel でそのまま開ける UTF-8 BOM 付き）／ JSON の書き出し・読み込み
  - ライン全体表示：工程別マトリクス＋工程別統計＋バランス効率
  - 工程表示：サイクル明細＋要素別統計

## キーボード操作

| キー | 動作 |
| --- | --- |
| `Space` / `Enter` | 1工程目のラップ（次の要素へ・サイクル完了） |
| `1` … `6` | その番号の工程のラップ |
| `P` | 一時停止 / 再開 |
| `Z` | 直前を取消（1工程目） |

## 計測データの持ち方

計測は「計測開始からの累積時間（ms）」の区切り位置だけを記録します。時計は1本で、
どの工程のサイクルも同じ時間軸の上に乗ります。

```js
process = {
  id: 'k3f…', name: '組立2',
  elements: [{ id, name }],   // 1個なら1タップで1サイクル
  cycles: [{
    startAcc: 12345,          // サイクル開始時点の累積経過(ms)
    marks:    [15000, 22000], // 各要素作業を終えた時点の累積経過(ms)
    excluded: false,          // 統計から除外するか
    note:     '',             // メモ
    at:       '2026-08-19T…'  // 記録時刻
  }],
  cycleStart: 22000,          // 計測中サイクルの開始
  pending:    []              // 計測中サイクルの確定済み区切り
}
```

各要素の所要時間は隣り合う区切りの差分として計算されるため、取り消し操作をしても
時間のつじつまが合わなくなりません。旧バージョン（単一工程）の保存データは、
読み込み時に1工程として自動で取り込まれます。

保存先は同一ブラウザの `localStorage` のみで、外部への送信は一切ありません
（キー: `ct-checker:v1` / `ct-checker:sessions:v1` / `ct-checker:theme`）。
端末を移すときは JSON で書き出してください。

## ファイル構成

```
index.html               画面
assets/styles.css        スタイル（ライト／ダークのトークン定義を含む）
assets/app.js            計測ロジック・集計・SVG グラフ描画
scripts/build-single.mjs 単一 HTML を生成するビルドスクリプト
```

依存パッケージはありません（ビルドスクリプトの実行にのみ Node.js を使用）。
