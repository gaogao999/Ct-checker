⏱ CT Checker サイクルタイム測定

使い方

ステーション（実際に人が立つ持ち場）ごとのストップウォッチです。工程はステーションをまとめる箱で、色分けと集計に使います。

  1. 設定で測りたいステーションを登録します（工程は分けたいときだけでOK）。タクトタイムもここで入れます。
  2. カードをタップするとスタート、もう一度タップでストップ。ストップウォッチと同じ動きです。
  3. 止めた時間でよければ保存を押すと1サイクルとして記録され、0に戻ります。測り直すときはリセット。
  4. 止めずに保存を押すと、その時点で区切って計測を続けます（連続で測りたいときに便利）。
  5. ステーションが多いときは、計測パネル上部の工程チップで表示を1工程に絞れます。
  6. 集計・グラフ・明細は表示切替で「ライン全体 → 工程 → ステーション」と掘り下げられます。外れた値は明細の「除外」で統計から外せます。
  7. 画面の切り替えは下のタブのほか、左右スワイプでもできます。
  8. データは自動でブラウザに保存されます。測定を保存すると名前を付けて残せ、CSV / JSON で書き出せます。

キーボード操作

  • Space / Enter 先頭ステーションのスタート / ストップ
  • 1…9 カード右上の番号のステーションのスタート / ストップ
  • S 保存　　P 表示中をまとめてスタート / ストップ　　Z 直前のサイクルを取消
